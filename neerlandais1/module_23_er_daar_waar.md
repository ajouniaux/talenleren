# Module 23 — *Waar denk je aan?* · Les adverbes pronominaux

| | |
|---|---|
| **Niveau** | A2 · UE1 · bloc 5 |
| **Durée** | 2 séances de 90 min (séance 1 : diapos 1–14, ex. 1 et 2 · séance 2 : diapos 15–22, ex. 3 à 7) |
| **Source** | Création (aucune archive) |
| **Prérequis** | M11 (particule au bout : la pince), M13 (*niet*), M17 (prépositions), M20 (*dit / dat*), M22 (*waarmee*, relatifs) |
| **Savoir-faire visés** | ① Remplacer « préposition + chose » par *er- / daar- / waar-* + préposition · ② Utiliser les verbes à préposition fixe (*denken aan, wachten op, praten over…*) · ③ Poser des questions et y répondre (*Waar wacht je op? — Daar wacht ik ook op.*) |

## Choix didactiques

**Points d'appui dans le parcours**
- *er / daar / waar / hier* correspondent à *het / dat / wat / dit* (M20, M22) quand il y a une préposition.
- Les deux morceaux se séparent comme une particule (M11) : *Ik denk **er** vaak **aan**.*
- *niet* se place avant la préposition, comme avant la particule (M13).

**Pièges FR ≠ NL ciblés**
- Le néerlandais refuse « préposition + *het / dat / wat* » pour une chose : ✗ *met het* → ✓ *ermee*.
- Les personnes gardent « préposition + pronom » : *Ik denk aan haar.*
- Les prépositions ne se traduisent pas mot à mot : « attendre » → *wachten **op***, « avoir envie de » → *zin hebben **in***.

**Décisions**
- Schéma **S19** « le tableau de conversion » : *het → er*, *dit → hier*, *dat → daar*, *wat → waar*, + préposition (*met → mee*).
- 12 verbes à préposition fixe, appris « en bloc » avec leur préposition.
- Les autres emplois de *er* (lieu, « il y a », « en ») sont donnés en aperçu.

### [DIAPOSITIVE 1 : Waar denk je aan?]

**Objectif pédagogique** — Annoncer le thème : parler d'une chose sans la répéter.

**Visuel / Schéma / Agencement**
- Couverture sombre.
- *À droite* : un personnage pensif avec une bulle de pensée contenant un calendrier ; deux bulles de dialogue : *Waar denk je aan?* / *Aan de deadline. Ik denk er de hele dag aan!*

**Contenu textuel**
> **Module 23 · Waar denk je aan?**
> Les adverbes pronominaux : *er, daar, waar* + préposition
> *Ik denk eraan. · Waarmee schrijf je?*

**Notes pour l'animateur** — Question d'entrée : « Comment dit-on *J'y pense* ? » Le néerlandais n'a ni « y » ni « en » : il combine *er* et une préposition.

---

### [DIAPOSITIVE 2 : Missie van vandaag]

**Objectif pédagogique** — Rendre les objectifs explicites.

**Visuel / Schéma / Agencement**
- Pastille `MISSIE`.
- 3 cartes avec icône : flèches de conversion (Remplacer), lien (Combiner), point d'interrogation (Questionner).

**Contenu textuel**
> 🔄 **Remplacer** — Je remplace « préposition + chose » : *met de pen → ermee.*
> 🔗 **Combiner** — J'apprends le verbe avec sa préposition : *wachten op, denken aan.*
> ❓ **Questionner** — Je demande et je réponds : *Waar wacht je op? — Op de bus.*

**Notes pour l'animateur** — Ces petits mots sont partout à l'oral : *Ik ben ermee bezig. Daar heb ik geen zin in. Waar gaat het over?*

### [DIAPOSITIVE 3 : Échauffement — au bureau]

**Objectif pédagogique** — Découvrir les formes dans un dialogue.

**Visuel / Schéma / Agencement**
- Sofie et Karim au bureau, 4 bulles alternées ; *er / daar* en vert, la préposition en orange.
- *En bas* : la question-guide.

**Contenu textuel**
> *Sofie: Heb je de offerte al gestuurd?* — *Karim: Nee, ik ben **er** nog **mee** bezig.*
> *Sofie: Denk je **eraan**? Het is dringend!* — *Karim: Ja, ik denk **er** de hele dag **aan**!*
> Que remplacent *er… mee* et *eraan* ?

**Notes pour l'animateur** — Faites retrouver le nom remplacé : *er… mee = met de offerte*, *eraan = aan de offerte*. *bezig zijn met* = être occupé à ; *dringend* = urgent.

### [DIAPOSITIVE 4 : Pas de « préposition + het » pour une chose]

**Objectif pédagogique** — Comprendre la conversion *het / dat / wat / dit* → *er / daar / waar / hier*.

**Visuel / Schéma / Agencement**
- Schéma **S19** « le tableau de conversion » : 4 lignes, chaque pronom barré se transforme en adverbe (flèche), avec un exemple.

**Contenu textuel**
> ✗ *op **het*** → ✓ ***er**op* — *Ik wacht erop.*
> ✗ *op **dat*** → ✓ ***daar**op* — *Daar wacht ik al lang op!*
> ✗ *op **wat*** → ✓ ***waar**op* — *Waarop wacht je?*
> ✗ *op **dit*** → ✓ ***hier**op* — *Hierop staat je naam.*

**Notes pour l'animateur** — Pour une chose, la préposition ne se combine jamais avec *het, dat, wat, dit*. *er* = neutre, *daar* = « ça » (insistance, ce qu'on vient de dire), *waar* = question ou relatif (M22), *hier* = « ceci ».

---

### [DIAPOSITIVE 5 : met → mee, tot → toe]

**Objectif pédagogique** — Retenir les deux prépositions qui changent de forme.

**Visuel / Schéma / Agencement**
- Deux briques « transformation » : *met → mee*, *tot → toe*, avec 3 exemples chacune.

**Contenu textuel**
> **met → mee** : *ermee · daarmee · waarmee* — *Waarmee betaal je? — Ik betaal ermee.*
> **tot → toe** : *ertoe · waartoe* (plus rare)
> Les autres ne changent pas : *eraan, erop, erover, ervan, erin, ernaar, ervoor*

**Notes pour l'animateur** — *met → mee* est très fréquent : *Wat doe je ermee? Ik ben ermee bezig.* *tot → toe* est surtout écrit : à reconnaître.

### [DIAPOSITIVE 6 : PIÈGE — une personne ou une chose ?]

**Objectif pédagogique** — Garder « préposition + pronom » pour les personnes.

**Visuel / Schéma / Agencement**
- Encadré **S10** à 2 colonnes : personne (bleu) / chose (vert), avec une illustration.

**Contenu textuel**
> « Je pense à **elle** » (une personne) → *Ik denk **aan haar**.*
> « J'**y** pense » (le rendez-vous) → ✗ ~~*Ik denk aan het.*~~ → ✓ *Ik denk **eraan**.*
> « Je travaille avec **lui** » → *Ik werk **met hem**.* · « Je travaille **avec** (l'ordinateur) » → *Ik werk **ermee**.*

**Notes pour l'animateur** — Question-réflexe : « une personne ou une chose ? » Personne → préposition + *hem, haar, hen…* ; chose → *er* + préposition. À l'oral, on entend parfois *ermee* pour un animal ; pour une personne, jamais.

### [DIAPOSITIVE 7 : Les deux morceaux se séparent]

**Objectif pédagogique** — Placer *er / daar / waar* et la préposition dans la phrase.

**Visuel / Schéma / Agencement**
- Bandes de phrase : *er / daar* en vert au milieu, la préposition en orange à la fin (comme une particule, M11).
- *En bas* : la place de *niet*.

**Contenu textuel**
> *Ik denk **er** vaak **aan**.* · ***Daar** heb ik geen zin **in**.* · ***Waar** wacht je **op**?*
> Avec *niet* : *Ik denk **er** niet **aan**.* (= je n'y pense pas / pas question !)
> Collés aussi possible : *Ik denk eraan. · Waarop wacht je?* (plus formel)

**Notes pour l'animateur** — À l'oral, la séparation est la règle : *Waar wacht je op?* La préposition va au bout, comme la particule (M11). *Ik denk er niet aan!* signifie aussi « il n'en est pas question ».

### [DIAPOSITIVE 8 : Les verbes à préposition fixe]

**Objectif pédagogique** — Apprendre 12 verbes fréquents avec leur préposition.

**Visuel / Schéma / Agencement**
- 12 cartes en grille 4 × 3, chacune avec une illustration, le verbe + préposition (préposition en orange) et la traduction.

**Contenu textuel**
> *denken **aan*** (penser à) · *wachten **op*** (attendre) · *praten **over*** (parler de) · *houden **van*** (aimer)
> *zin hebben **in*** (avoir envie de) · *bezig zijn **met*** (être occupé à) · *zorgen **voor*** (s'occuper de) · *kijken **naar*** (regarder)
> *luisteren **naar*** (écouter) · *beginnen **met*** (commencer par) · *stoppen **met*** (arrêter de) · *rekenen **op*** (compter sur)

**Notes pour l'animateur** — On apprend le verbe et sa préposition en bloc, comme un mot composé. Exemples : *Ik heb zin in koffie. · Wie zorgt voor de lunch? · Ik reken op jou!*

---

### [DIAPOSITIVE 9 : PIÈGE — les prépositions ne se traduisent pas]

**Objectif pédagogique** — Éviter de traduire la préposition française.

**Visuel / Schéma / Agencement**
- Encadré **S10** à 4 lignes : FR (préposition française barrée ou absente) → NL (préposition néerlandaise entourée).

**Contenu textuel**
> « attendre **le** bus » (pas de préposition) → *wachten **op** de bus*
> « avoir envie **d'**un café » → *zin hebben **in** een koffie*
> « dépendre **de** » → *afhangen **van*** — *Dat hangt **ervan** af.*
> « s'occuper **de** » → *zorgen **voor*** — ✗ ~~*zorgen van*~~

**Notes pour l'animateur** — Le français « de » peut devenir *van, in, voor, over, met*… Seule solution : la carte « verbe + préposition ». *Dat hangt ervan af* (« ça dépend ») est une expression à apprendre telle quelle.

### [DIAPOSITIVE 10 : Poser une question : waar… op ? op wie ?]

**Objectif pédagogique** — Poser des questions sur une chose ou une personne.

**Visuel / Schéma / Agencement**
- Deux colonnes : chose (*waar + prép.*, vert) / personne (*prép. + wie*, bleu), 3 paires de questions-réponses.

**Contenu textuel**
> chose : ***Waar** wacht je **op**? — Op de bus.* · ***Waar** denk je **aan**? — Aan mijn vakantie.* · ***Waarmee** betaal je? — Met mijn kaart.*
> personne : ***Op wie** wacht je? — Op An.* · ***Aan wie** denk je? — Aan mijn moeder.* · ***Met wie** praat je? — Met Sofie.*

**Notes pour l'animateur** — Même logique que la diapo 6. La réponse courte reprend la préposition : *Op de bus.* Faites jouer les questions en chaîne autour de la classe.

---

### [DIAPOSITIVE 11 : Dans une relative : waarmee, waarover]

**Objectif pédagogique** — Utiliser *waar* + préposition comme relatif (lien M22).

**Visuel / Schéma / Agencement**
- Schéma **S12** (le wagon) : le nom, puis *waar* + préposition, puis le verbe à la fin.
- 3 exemples avec une illustration.

**Contenu textuel**
> *de pen **waarmee** ik schrijf · het project **waaraan** ik werk · de stoel **waarop** je zit*
> À l'oral, souvent séparé : *het project **waar** ik **aan** werk*
> Personnes : *de collega **met wie** ik werk* (M22)

**Notes pour l'animateur** — ✗ *de pen met die ik schrijf* : pour une chose, on dit *waarmee*. C'est l'équivalent de « avec lequel, sur laquelle, dont » : *het boek waarover ik praat* (le livre dont je parle).

### [DIAPOSITIVE 12 : + APERÇU — les autres emplois de er]

**Objectif pédagogique** — Reconnaître les quatre emplois de *er*.

**Visuel / Schéma / Agencement**
- Schéma « le couteau suisse » : 4 lames, une par emploi de *er*, avec un exemple chacune ; la lame de ce module est mise en valeur.

**Contenu textuel**
> ① lieu (= « y », « là ») : *Ken je Gent? Ik woon **er** al tien jaar.*
> ② « il y a » : ***Er** is een probleem. · **Er** zijn veel klanten.*
> ③ avec un nombre (= « en ») : *Hoeveel kinderen heb je? Ik heb **er** twee.*
> ④ + préposition (ce module) : *Ik denk **eraan**.*

**Notes pour l'animateur** — À reconnaître : *er* a plusieurs « métiers ». Le contexte suffit presque toujours. Les emplois ①–③ sont travaillés en Néerlandais 2.

### [DIAPOSITIVE 13 : À retenir — la fiche er / daar / waar]

**Objectif pédagogique** — Synthèse à photographier.

**Visuel / Schéma / Agencement**
- Pastille `À RETENIR`.
- 3 blocs : Convertir · Placer · Questionner.

**Contenu textuel**
> **Convertir** : chose → *er / daar / waar / hier* + préposition (*met → mee*) · personne → préposition + *hem / haar / wie*
> **Placer** : les deux morceaux se séparent — *Ik denk er vaak aan. · Ik denk er niet aan.*
> **Questionner** : *Waar wacht je op? · Op wie wacht je?* · relatif : *de pen waarmee ik schrijf*

**Notes pour l'animateur** — Ce schéma est la référence pour tous les exercices. La liste des 12 verbes (diapo 8) est à apprendre par cœur.

### [DIAPOSITIVE 15 : Exercice 1 — Remplacez ★]

**Objectif pédagogique** — Remplacer « préposition + chose » par *er* + préposition.

**Visuel / Schéma / Agencement**
- Gabarit **E3** : 6 phrases (la chose soulignée) → flèche « *er* » → carte vide.

**Contenu textuel**
> 1 *Ik schrijf met de pen.* · 2 *Ik wacht op de bus.* · 3 *Hij praat over het project.* · 4 *We beginnen met de vergadering.* · 5 *Ik denk aan de afspraak.* · 6 *Ze houdt van chocolade.*
>
> **✓ CORRECTIE** — 1 *Ik schrijf ermee.* · 2 *Ik wacht erop.* · 3 *Hij praat erover.* · 4 *We beginnen ermee.* · 5 *Ik denk eraan.* · 6 *Ze houdt ervan.*

**Notes pour l'animateur** — N° 1 et 4 : *met → mee*. Variante : ajoutez *niet* ou un adverbe pour forcer la séparation (*Ik denk er vaak aan.*).

### [DIAPOSITIVE 16 : Exercice 2 — Le verbe et sa préposition ★]

**Objectif pédagogique** — Mémoriser les verbes à préposition fixe.

**Visuel / Schéma / Agencement**
- Gabarit **E1** : 8 phrases à trous ; banque des prépositions à droite.

**Contenu textuel**
> 1 *Ik wacht …… de trein.* · 2 *Denk je …… de vergadering?* · 3 *We praten …… het budget.* · 4 *Hij houdt …… koken.*
> 5 *Ik heb zin …… een koffie.* · 6 *Ze is bezig …… een rapport.* · 7 *Wie zorgt …… de lunch?* · 8 *Ik kijk …… het nieuws.*
> Banque : *in · naar · op · met · van · voor · aan · over*
>
> **✓ CORRECTIE** — 1 *op* · 2 *aan* · 3 *over* · 4 *van* · 5 *in* · 6 *met* · 7 *voor* · 8 *naar*

**Notes pour l'animateur** — Une préposition par phrase, chacune utilisée une fois. Prolongez : faites remplacer le complément par *er* (*Ik wacht erop.*).

### [DIAPOSITIVE 17 : Exercice 3 — Posez la question ★★]

**Objectif pédagogique** — Former la question avec *waar* + préposition ou préposition + *wie*.

**Visuel / Schéma / Agencement**
- Gabarit **E3** : 6 réponses (le complément souligné) → carte vide pour la question.

**Contenu textuel**
> 1 *Ik wacht op de bus.* · 2 *Ik denk aan mijn vakantie.* · 3 *Ik betaal met mijn kaart.* · 4 *Ik praat met Sofie.* · 5 *Ik wacht op An.* · 6 *We praten over het budget.*
>
> **✓ CORRECTIE** — 1 *Waar wacht je op?* · 2 *Waar denk je aan?* · 3 *Waarmee betaal je?* (ou *Waar betaal je mee?*) · 4 *Met wie praat je?* · 5 *Op wie wacht je?* · 6 *Waarover praten jullie?* (ou *Waar praten jullie over?*)

**Notes pour l'animateur** — Faites d'abord trier : chose (n° 1, 2, 3, 6) ou personne (n° 4, 5) ? Les formes collées (*Waarop wacht je?*) sont aussi correctes.

### [DIAPOSITIVE 18 : Exercice 4 — Chose ou personne ? ★★]

**Objectif pédagogique** — Choisir entre *er* + préposition et préposition + pronom.

**Visuel / Schéma / Agencement**
- Gabarit **E1** : 6 mini-contextes de deux phrases, avec une illustration (personne ou objet).

**Contenu textuel**
> 1 *Mijn moeder is ziek. Ik denk vaak …… .* · 2 *De deadline is morgen. Denk je …… ?* · 3 *Dit is mijn nieuwe laptop. Ik werk graag …… .*
> 4 *Dit is mijn nieuwe collega. Ik werk graag …… .* · 5 *De bus is laat. We wachten al lang …… .* · 6 *Sofie is laat. We wachten al lang …… .*
>
> **✓ CORRECTIE** — 1 *aan haar* · 2 *eraan* · 3 *ermee* · 4 *met hem* (ou *met haar*) · 5 *erop* · 6 *op haar*

**Notes pour l'animateur** — Les paires 3-4 et 5-6 sont construites en miroir : même verbe, même préposition, mais une chose / une personne.

### [DIAPOSITIVE 19 : Exercice 5 — Le détective ★★]

**Objectif pédagogique** — Corriger les erreurs typiques dans un courriel.

**Visuel / Schéma / Agencement**
- Gabarit **E6** : le courriel de Karim à An, avec la loupe et le compteur « 5 erreurs ».

**Contenu textuel**
> « *Beste An, het rapport is nog niet klaar, maar ik werk er elke dag aan. De klant wacht op het, maar ik kan het vrijdag sturen. Gisteren heb ik met Sofie over het budget gepraat. Ze heeft goede ideeën en ik ben blij met het. Lotte is een goede stagiaire: ik werk graag ermee. Over het nieuwe project: met wat moet ik eerst beginnen? Ik heb nog twee vragen over het. Groeten, Karim* »
>
> **✓ CORRECTIE** — ~~*wacht op het*~~ **wacht erop** · ~~*ik ben blij met het*~~ **ik ben er blij mee** · ~~*ik werk graag ermee*~~ **ik werk graag met haar** · ~~*met wat*~~ **waarmee** · ~~*Ik heb nog twee vragen over het*~~ **Ik heb er nog twee vragen over**

**Notes pour l'animateur** — Leurres : *ik werk er elke dag aan* et *met Sofie over het budget* (personne, puis nom) sont corrects. N° 3 : Lotte est une personne (diapo 6). N° 4 : *Waar moet ik eerst mee beginnen?* est aussi correct.

### [DIAPOSITIVE 20 : Exercice 6 — L'interview ★]

**Objectif pédagogique** — Poser des questions personnelles avec *waar* + préposition.

**Visuel / Schéma / Agencement**
- Gabarit **E7** : 6 cartes-questions illustrées, règles en 3 puces.

**Contenu textuel**
> *Waar heb je zin in? · Waar ben je bang voor? · Waar droom je van? · Waar ben je trots op? · Waar ben je goed in? · Waar kijk je naar uit?*
> 1. Par deux : posez 4 questions, notez les réponses.
> 2. Réagissez : *Daar ben ik ook bang voor! · Daar heb ik geen zin in!*
> 3. Présentez votre partenaire à la classe.

**Notes pour l'animateur** — *bang zijn voor* (avoir peur de), *dromen van* (rêver de), *trots zijn op* (être fier de), *goed zijn in* (être bon en), *uitkijken naar* (avoir hâte de). Les réactions avec *daar* (diapo 4) sont l'objectif principal.

### [DIAPOSITIVE 21 : Exercice 7 — La réunion de suivi ★★★]

**Objectif pédagogique** — Mise en situation professionnelle : faire le point sur les tâches.

**Visuel / Schéma / Agencement**
- Gabarit **E8** : carte A (An, la cheffe) / carte B (un membre de l'équipe).
- Document : un tableau de tâches à 3 colonnes (*te doen · bezig · klaar*) ; banque de phrases.

**Contenu textuel**
> **Situation** : lundi matin, An fait le point avec chaque membre de l'équipe.
> Banque : *Waar ben je mee bezig? · Ik ben bezig met de facturen. · Heb je aan de offerte gedacht? — Ja, ik heb eraan gedacht. · Waar wacht je nog op? — Ik wacht op het antwoord van de klant. · Daar zorg ik voor. · Kun je erop letten?*

**Notes pour l'animateur** — *letten op* = faire attention à ; *zorgen voor* = s'occuper de. Chaque membre déplace ses tâches sur le tableau en expliquant. Exigez au moins deux *er* + préposition.
