## Analyse critique de l'archive

**Forces conservées**
- La grille à deux éléments verbaux (② auxiliaire, ⑥ participe), avec les cercles rouges.
- Le moyen mnémotechnique **« SoFT KetCHuP »** pour le choix *t / d*, avec la décomposition *GE + DANS + T*.
- Les verbes à particule au passé : *BIJ + GE + LEER + D*.
- Les cartes infinitif → participe, avec une phrase en contexte.
- Le ⚠ sur *reizen → gereisd* et *leven → geleefd* : le choix *t / d* se fait sur l'infinitif (*z, v*), pas sur le radical ajusté.
- Le jeu « *Heb je (n)ooit…?* ».

**Faiblesses corrigées**
- **La diapo des préfixes (10) mélange imparfait et participe** : *bedroog, herzag, bestond, betrok, geleek* sont des imparfaits ; *gebaren* est un infinitif, et l'on trouve un mot inexistant (*eruigezien*). Elle est remplacée par une diapo claire : les inséparables n'ont **pas de *ge-*** (*betaald, vergeten, ontmoet*).
- Phrases fautives ou peu naturelles :
  - *We hebben de laatste jaar* → *de laatste jaren* ;
  - *continen* → *continenten* ;
  - *Ik heb het deze laatste jaren financieel moeilijk. Ik heb … geleefd* (présent incohérent) ;
  - *Ik heb een koekje opgemaakt* (*opeten*) ;
  - *Ze hebben vandaag met de leraar meegemaakt* (complément manquant) ;
  - *We hebben … onze vakantie beleefd* (redondant, voir M3).
- *Ik heb een Blind date gedaan* : majuscule et tournure → *Ik ben op een blind date geweest.*
- Le choix *hebben / zijn* n'est jamais expliqué, et le piège « j'ai été = *ik ben geweest* » n'est pas traité.
- Étiquette « Niveau UE 2 » : le passé composé est ici rattaché à la fin de l'UE1, comme synthèse.

**Décisions**
- Le participe est une **chaîne de montage** (schéma S5) : *ge* + radical + *t / d*.
- *hebben / zijn* : deux portes, la grande (*hebben*, 90 %) et la petite (*zijn* : déplacement, changement, *blijven, zijn*).
- Dix-sept irréguliers fréquents, regroupés par familles de voyelles.
- Le module se termine par le **bilan des blocs 1 à 3** (M1–M15) ; le bilan final du parcours est au M24.

### [DIAPOSITIVE 4 : La pince du passé]

**Objectif pédagogique** — Situer le passé composé dans la grille (archive diapo 3, phrases corrigées).

**Visuel / Schéma / Agencement**
- Grille **S2** :
  - ② auxiliaire *hebben / zijn* (rouge cerclé) ;
  - ⑥ participe (rouge pointillé).
- 5 lignes. *En bas* : la ligne française en vis-à-vis, avec les deux verbes collés.

**Contenu textuel**
> *Ik **heb** een koekje **gegeten**.* · *Jij **bent** naar Frankrijk **verhuisd**.* · *Hij **heeft** deze week 32 uur **gewerkt**.*
> *We **zijn** voor het examen **geslaagd**.* · *Ze **hebben** vandaag een opleiding **gevolgd**.*
> FR : J'**ai mangé** un biscuit. (collés) → NL : *Ik **heb** … **gegeten**.* (séparés)

**Notes pour l'animateur** — C'est la pince du M3, avec l'auxiliaire comme mâchoire gauche. *verhuizen* (déménager) remplace *verkassen* (familier). *slagen* (réussir un examen) se conjugue avec *zijn*.

### [DIAPOSITIVE 5 : Le participe régulier : ge + radical + t/d]

**Objectif pédagogique** — Former le participe des verbes réguliers.

**Visuel / Schéma / Agencement**
- Chaîne de montage **S5** à 3 stations :
  1. ✂ radical (M3) ;
  2. ➕ *ge-* devant ;
  3. ➕ *t* ou *d* derrière.
- Deux mots voyagent : *werken* et *wonen*.

**Contenu textuel**
> *werken* → *werk* → ***ge**werk**t*** · *wonen* → *woon* → ***ge**woon**d***
> *maken → gemaakt · spelen → gespeeld · bellen → gebeld · leren → geleerd*

**Notes pour l'animateur** — Les ajustements de radical du M3 s'appliquent (*woon, maak, bel*). *t* ou *d* : diapo suivante. À l'oral, *gewoond* se prononce avec un *t* final (M1) : la différence n'existe qu'à l'écrit.

### [DIAPOSITIVE 6 : t ou d ? — SoFT KetCHuP]

**Objectif pédagogique** — Choisir *t* ou *d* (mnémotechnique de l'archive, standardisée).

**Visuel / Schéma / Agencement**
- Le mot **SoFT KetCHuP** en grand. Les consonnes *s, f, t, k, ch, p* sont en orange, les voyelles en gris.
- Règle : la **dernière lettre du radical** est dans *SoFT KetCHuP* → **t** ; sinon → **d**.
- 2 colonnes d'exemples (t / d), avec le radical souligné.

**Contenu textuel**
> **t** : *dansen → gedans**t** · smaken → gesmaak**t** · kussen → gekus**t** · stoppen → gestop**t***
> **d** : *bellen → gebel**d** · wonen → gewoon**d** · luisteren → geluister**d** · leren → geleer**d***
> Radical en *t* ou *d* : pas de lettre en plus — *wachten → gewacht · zetten → gezet · antwoorden → geantwoord*

**Notes pour l'animateur** — Exemples de l'archive. En Flandre, on apprend aussi « *'t kofschip* » (mêmes consonnes). La 3e ligne réutilise la règle du M4 (*hij wacht*, pas *wachtt*).

### [DIAPOSITIVE 7 : PIÈGE — reizen, leven : on regarde l'infinitif]

**Objectif pédagogique** — Neutraliser l'erreur *gereist / geleeft* (⚠ de l'archive).

**Visuel / Schéma / Agencement**
- Encadré **S10** à deux lignes.
  - *reizen* → radical *reis* (avec *s*) → ✗ ~~*gereist*~~ → ✓ *gereis**d***.
  - *leven* → *leef* → ✗ ~~*geleeft*~~ → ✓ *gelee**fd***.
- Une flèche remonte vers le *z* / *v* de l'infinitif.

**Contenu textuel**
> *reizen* (z) → ✓ *gereisd* · *leven* (v) → ✓ *geleefd* · *verhuizen* (z) → ✓ *verhuisd*
> Règle : *z* et *v* ne sont pas dans *SoFT KetCHuP* → **d**, même si le radical s'écrit *s* ou *f*.

**Notes pour l'animateur** — Lien M4 (*reizen → ik reis*). Phrases de l'archive, corrigées : *We hebben de laatste jaren veel gereisd. We hebben verschillende continenten bezocht.*

### [DIAPOSITIVE 8 : Verbes à particule et verbes inséparables]

**Objectif pédagogique** — Placer *ge-* au bon endroit, ou ne pas le mettre (archive diapos 6 et 10, corrigées).

**Visuel / Schéma / Agencement**
- *Gauche*, séparables (orange, ✂️) : la particule, puis *ge*, puis le radical, puis *t / d*, en 4 briques — *op | ge | staan*.
- *Droite*, inséparables (bleu nuit, 🔒) : le préfixe garde sa place et ***ge-* disparaît** (ge barré).

**Contenu textuel**
> ✂️ *opstaan → op**ge**staan · meenemen → mee**ge**nomen · inloggen → in**ge**logd · bijleren → bij**ge**leerd*
> 🔒 *betalen → betaald · vertellen → verteld · ontmoeten → ontmoet · herhalen → herhaald* (✗ ~~*gebetaald*~~)

**Notes pour l'animateur** — Lien M11 : les mêmes tests (préfixe, accent). Un participe commence donc par *ge-*, par une particule + *ge-*, ou par un préfixe inséparable. *ontmoet* : radical en *t*, pas de *t* ajouté.

### [DIAPOSITIVE 9 : Les irréguliers fréquents]

**Objectif pédagogique** — Mémoriser 17 participes irréguliers parmi les plus utiles.

**Visuel / Schéma / Agencement**
- Pastille `À RETENIR`.
- 5 familles colorées selon la voyelle, chacune dans une carte avec infinitif → participe.
- Une carte spéciale ⭐ pour *hebben / zijn*.

**Contenu textuel**
> **e** : *eten → gegeten · lezen → gelezen · zien → gezien · geven → gegeven*
> **o** : *nemen → genomen · komen → gekomen · spreken → gesproken · beginnen → begonnen · drinken → gedronken*
> **ij → e** : *schrijven → geschreven · blijven → gebleven · krijgen → gekregen*
> **aa** : *gaan → gegaan · staan → gestaan · doen → gedaan*
> ⭐ *hebben → gehad · zijn → geweest*

**Notes pour l'animateur** — On les apprend par familles sonores. *begonnen* n'a pas de *ge-* (*be-*, inséparable). Liste complète en annexe de Néerlandais 2.

### [DIAPOSITIVE 10 : hebben ou zijn ?]

**Objectif pédagogique** — Choisir l'auxiliaire.

**Visuel / Schéma / Agencement**
- Deux portes illustrées :
  - une grande porte **HEBBEN** (« presque tous les verbes ») ;
  - une petite porte **ZIJN** avec 3 pictogrammes : déplacement de A vers B (flèche), changement d'état (chenille → papillon), *zijn / blijven* (ancre).

**Contenu textuel**
> **hebben** : la plupart des verbes — *Ik heb gewerkt / gegeten / geslapen.*
> **zijn** : déplacement vers un lieu — *Ik ben naar Gent gegaan. · Hij is gekomen. · We zijn vertrokken.*
> changement — *Ze is opgestaan. · Hij is ziek geworden. · Ik ben geslaagd.*
> rester / être — *Ik ben thuis gebleven. · Ik ben in Parijs geweest.*

**Notes pour l'animateur** — Le français fonctionne presque pareil (« je suis allé, je suis parti »). Les exceptions françaises sont la diapo suivante. *fietsen, lopen* peuvent prendre les deux : à voir en Néerlandais 2.

### [DIAPOSITIVE 11 : PIÈGE — « j'ai été », « j'ai commencé »]

**Objectif pédagogique** — Corriger les auxiliaires qui diffèrent du français.

**Visuel / Schéma / Agencement**
- Encadré **S10** à 3 lignes (FR « avoir » barré → NL *zijn* en vert).

**Contenu textuel**
> « J'**ai été** malade. » → ✗ ~~*Ik heb ziek geweest.*~~ → ✓ *Ik **ben** ziek **geweest**.*
> « J'**ai commencé** à 9 h. » → ✓ *Ik **ben** om 9 uur **begonnen**.*
> « J'**ai réussi** l'examen. » → ✓ *Ik **ben** voor het examen **geslaagd**.*

**Notes pour l'animateur** — Trois verbes très fréquents dans les conversations professionnelles (maladie, horaires, examens). Le français « avoir » devient *zijn* : faites-les répéter en chœur.

### [DIAPOSITIVE 12 : Les mots du passé]

**Objectif pédagogique** — Situer l'action dans le temps.

**Visuel / Schéma / Agencement**
- Une frise horizontale de « il y a longtemps » à « maintenant ». Les marqueurs sont placés dessus, chacun avec une petite icône.

**Contenu textuel**
> *vorig jaar · vorige maand · vorige week · drie dagen geleden · gisteren · vanmorgen · net*
> *al* (déjà) · *nog niet* (pas encore) · *ooit* (déjà, une fois) · *nooit* (jamais)

**Notes pour l'animateur** — *geleden* = « il y a » (temps) : *twee jaar geleden*. *vorig jaar* (het jaar) mais *vorige week* (de week) : l'adjectif prend *-e* devant un nom *de* (aperçu, Néerlandais 2). *net* = « venir de » : *Ik heb net gegeten.*

### [DIAPOSITIVE 13 : Questions, négation, inversion]

**Objectif pédagogique** — Réinvestir la grille au passé (lien M3, M13).

**Visuel / Schéma / Agencement**
- Trois blocs :
  - question (auxiliaire en tête) ;
  - négation (*niet* avant le participe) ;
  - inversion (un complément en ①).
- La pince est surlignée dans chaque phrase.

**Contenu textuel**
> Question : ***Heb** je al **gegeten**? · Wat **heb** je **gedaan**? · Waar **ben** je **geweest**?*
> Négation : *Nee, ik **heb** nog **niet gegeten**. · Ik **heb** **geen** tijd **gehad**.*
> Inversion : *Gisteren **heb** ik thuis **gewerkt**. · Vorige week **zijn** we naar Brugge **gegaan**.*

**Notes pour l'animateur** — Rappel M13 : *niet* juste avant le participe ; *geen* devant le nom. Rappel M3 : complément en tête → inversion.

### [DIAPOSITIVE 15 : À retenir — l'organigramme du participe]

**Objectif pédagogique** — Synthèse à photographier.

**Visuel / Schéma / Agencement**
- Pastille `À RETENIR`.
- Organigramme **S9**, de haut en bas :
  1. « Irrégulier (liste) ? » → participe à apprendre ;
  2. « Préfixe *be-, ge-, ont-, ver-, er-, her-* ? » → pas de *ge-* ;
  3. « Particule ? » → particule + *ge* + radical + t/d ;
  4. sinon → *ge* + radical + t/d (SoFT KetCHuP).

**Contenu textuel**

> **zijn** : déplacement · changement · *blijven, zijn* — **hebben** : tout le reste

**Notes pour l'animateur** — Ce schéma est la référence pour tous les exercices.

**Objectif pédagogique** — Corriger les erreurs typiques dans un récit.
