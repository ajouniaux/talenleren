## Organisation de chaque présentation

1. **Couverture**, avec l’illustration de la scène.
2. **Today’s mission** : objectif de production, langue travaillée et déroulé indicatif (base 90 min).
3. **Warm-up** : réactivation de la séance précédente.
4. **Scènes et pièces du dossier** (Exhibits A, B, C) projetées en grand, avec une question à poser à la classe.
5. **Exercices du livret** (YOUR MOVE, DRY RUN, TEAM CALL, YOUR EXPERT) : une diapositive **question** (pointillés), puis une diapositive **✓ CORRECTION** (réponses en vert, erreurs barrées en rouge), avec un encadré EXPECTED / WATCH OUT.
6. **Grammaire en visuel** : fiches-formules, frises temporelles (barre = arrière-plan, point = événement), échelle de certitude des modaux, « Piège pour francophones ».
7. **Vocabulaire** : tableaux anglais / français / exemple tiré du dossier (WORD FILE).
8. **+ EXTRA** : exercices supplémentaires hors livret, signalés comme tels.
9. **Clôture** : *cliffhanger* de la scène suivante, travail à faire, ticket de sortie.

Les **notes du présentateur** (en français) donnent les consignes de conduite, les durées et les réponses alternatives acceptables.

## Style « séance 1 » (séances 04 à 08)

Les séances 04 à 08 suivent le modèle de la présentation de la première séance : fond blanc partout, une idée par diapositive, gros caractères, pas de pied de page ni d’encadré latéral. Le déroulé indicatif est dans les notes de la couverture.

Les textes d’écoute inventés (agent d’entretien, Objection!, expert IT, journaux de Back to the board) sont cohérents avec le dossier ; leurs scripts sont dans les notes du présentateur. Les diapositives GAME et + EXTRA sont facultatives.

Le code de ce style est dans `generateur/lib_light.js` ; une séance l’utilise avec `style: 'light'` dans son `meta`.

## Points à vérifier avant les cours

- **Messages vocaux (séances 2 et 13)** : les scripts audio ne sont pas dans le livret. Les corrections des prises de notes (séance 2, ligne 5 ; séance 13, Q1–Q3, Q5–Q6) sont des réponses probables, déduites du reste du dossier. Elles sont à ajuster à votre enregistrement. Les notes du présentateur le rappellent.
- **Livret p. 9** : la réplique 11 du dialogue manque (passage de 10 à 12).
- **Livret p. 25, Q5** : la phrase citée *« I have never seen this pipe before »* n’apparaît pas dans l’Exhibit B (p. 23).
- **Fiches des firmes (p. 45–46)** : *« Friday 14 November 2026 »*, alors que le 14 novembre 2026 est un **samedi**. Les présentations reproduisent les fiches telles quelles, mais le rapport modèle écrit « 14 November 2026 » sans le jour, et la diapositive sur les dates en fait un point d’attention.

## Régénérer les présentations

Le dossier `generateur/` contient le code source (un fichier par séance dans `generateur/sessions/`) et les illustrations extraites du livret. Pour modifier un contenu, éditez le fichier de la séance, puis :

```bash
cd generateur
npm install
npm run build   # réécrit les fichiers dans ../powerpoints
```
